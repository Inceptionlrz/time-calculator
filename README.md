# 时间计算器 (Time Calculator)

一个用于计算“截止日期”的单页 Web 工具，适用于“3 个日历日完成”“5 个工作日内提交”等场景。

## 功能

- 支持三种期限类型：
  - **日历日**：连续自然日（含周末与节假日）。
  - **自然日**：连续 24 小时为一天；计算语义与日历日一致，仅在 UI 上区分以消除歧义。
  - **工作日**：周一至周五，自动排除法定节假日；调休补班日计入工作日。
- 起始时间默认当前时间，可手动指定。
- 期限长度：正整数。
- 方向切换：正向（起始 + N）/ 反向（起始 − N）。
- “包含起始日当天”开关：勾选则从当天计为第 1 天，否则从次日开始。
- **两种推算模式**：
  - **起始 ± N 天**（默认）：给定起始日与 N，推算截止日。
  - **起止反推间隔**：给定起始日与截止日，反推两者之间相距多少工作日 / 日历日（P1-1，与倒计时同源）。
- **结果展示增强**：
  - 距“真实今天”的**剩余天数倒计时**（已过期为负数并显示“已过期”）。
  - **途经周末 / 法定节假日 / 调休补班日的具体日期列表**（可折叠展开）。
  - **复制结果**按钮：一键复制为纯文本（如 `截止日：2026-03-10 14:30，共5个工作日 …`）。
- **单休 / 自定义工作日历**：在“节假日 / 调休管理”中勾选每周休息日，可设置周六是否上班（单休模式）。法定节假日始终按地区规则优先排除。
- **地区切换**：支持**中国大陆** / **中国香港**节假日数据集。
- 内置 **2024–2027** 年节假日与调休安排，支持手动新增/删除节假日与调休补班日。

## 技术栈

Vite + React + TypeScript + Tailwind CSS（纯前端，无 MUI）。核心计算为纯函数。

## 启动

```bash
pnpm install
pnpm dev       # 本地开发，默认 http://localhost:5173
pnpm build     # 类型检查 + 生产构建，输出到 dist/
pnpm preview   # 预览生产构建
pnpm test      # 运行算法与组件渲染测试（esbuild 打包后由 node 执行）
```

> 若环境中未安装 pnpm，可改用 `npm install` / `npm run dev` 等等价命令。

## 计算规则说明

- **工作日判定**：调休补班日恒为工作日；否则为“非法定节假日 且 非休息日”。休息日来自可配置的 `WorkCalendarConfig`（默认 [周日, 周六]，即双休；单休为仅 [周日]）。
- **法定节假日优先级最高**：即便开启单休，落在法定节假日范围内的日期（含周六）一律排除。
- **包含起始日**：
  - 日历日 / 自然日：包含则从起始日计第 1 天（整体偏移 `N−1` 天），不含则偏移 `N` 天。
  - 工作日：包含则起始日若为工作日即计为第 1 个工作日。
- 自然日与日历日在本工具中计算等价（均按连续 24 小时推进），仅在 UI 上区分以避免歧义。
- **起止反推间隔**：日历日返回起止日相差整天数；工作日返回闭区间内工作日总数（含两端）。

## 验收基准（AC-1 校准）

- `2026-03-04`（周三）+ 5 工作日 → `2026-03-10`（周二），途经周末 2 天、法定节假日 0 天。
- `2026-06-17` + 5 工作日 → `2026-06-24`（端午法定假 `2026-06-19` 被正确跳过，故非 06-23）。该窗口已固化为回归测试，防止算法被误改回 06-23。

## 已知限制

- 中国大陆 2024–2026 年节假日采用国务院办公厅官方安排；**2027 年为按规律预估**，最终以国务院办公厅发布为准。
- 中国香港为常见主要公众假期（元旦、春节、耶稣受难节、复活节、劳动节、佛诞、端午节、特区成立纪念日、中秋节翌日、国庆节、重阳节、圣诞节等），具体以香港特区政府公布为准。
- 节假日数据内置为静态结构，不会自动联网更新，可在“节假日 / 调休管理”中手动修正。
- 未考虑半天班、跨时区（按运行设备本地时区）、公司级特殊排班等场景。
